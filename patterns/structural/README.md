# Patrones estructurales (Structural)

Resuelven cómo **combinar clases y objetos** en estructuras más grandes,
manteniéndolas flexibles y eficientes — por ejemplo, cómo hacer que dos
interfaces incompatibles trabajen juntas, o cómo tratar un grupo de objetos
igual que a uno solo.

| Patrón | En una frase |
|--------|--------------|
| [Adapter](adapter/README.md) | Hacer compatibles dos interfaces que no encajan. |
| [Bridge](bridge/README.md) | Separar una abstracción de su implementación para que varíen por separado. |
| [Composite](composite/README.md) | Tratar un objeto individual y un grupo de ellos de la misma forma. |
| [Decorator](decorator/README.md) | Agregarle comportamiento a un objeto sin modificar su clase. |
| [Facade](facade/README.md) | Una interfaz simple delante de un subsistema complicado. |
| [Flyweight](flyweight/README.md) | Compartir datos comunes entre muchos objetos para ahorrar memoria. |
| [Proxy](proxy/README.md) | Un sustituto que controla el acceso al objeto real. |

Volver al [índice de patrones](../README.md).
